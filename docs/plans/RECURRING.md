# Recurring findings

Mistakes that agents made more than once, and what now prevents each one. A finding that recurs gets a **check**
where one can catch it (type, lint rule, `tools/` scan, CI step); a **skill rule** only where no check can. The PR
that fixes a recurring finding adds its row here. Read this list before opening a PR (`/implement-pr` §4).
